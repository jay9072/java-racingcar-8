# java-racingcar-precourse

구현할 기능 목록

### 1. 입력 기능

1. 자동차 이름 입력받기 (쉼표 기준으로 구분)
2. 시도 횟수 입력받기
3. 잘못된 입력값일 경우 예외 발생시키기 (IllegalArgumentException)

### 2. 자동차 생성

1. 입력받은 이름으로 자동차 객체 생성
2. 이름 길이 5자 초과 시 예외 발생

### 3. 이동 로직

1. 0~9 사이 무작위 값 생성 (Randoms.pickNumberInRange(0,9))
2. 4 이상일 경우 전진, 미만일 경우 멈춤

### 4. 실행 결과 출력

1. 각 라운드별로 자동차 이름과 이동 결과 출력
2. ‘-’ 개수로 이동 거리 표시

### 5. 우승자 판별

1. 가장 멀리 간 자동차 탐색
2. 공동 우승자 있을 경우 쉼표로 구분 출력

### 6. 예외 처리 및 종료

1. 입력 예외 시 IllegalArgumentException 발생 후 종료
